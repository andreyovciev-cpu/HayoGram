# Hayo Gram

**Форк Telegram для Android от [Hayozimi](https://t.me/hayozimi).**

Переименованный форк [MargyGram](https://git.narez.xyz/narezany/MargyGram).
Пакет остаётся `cat.narezany.margygram` — меняется только то, что видит
пользователь, и добавляются два значка владельцев. Собирается из
[DrKLO/Telegram](https://github.com/DrKLO/Telegram) одним патчем `patch/hayo.patch`.

[English](README.md) · [Значки](docs/badges.md) · [Сборка](BUILD.ru.md) · [Безопасность](docs/security.md)

## Значки владельцев

Два эксклюзивных значка вшиты в сборку и лежат в [`badges.json`](badges.json):

| Ник | Значок | Цвет |
|---|---|---|
| `@hayozimi` | **Владелец** | зелёный, корона |
| `@zarrokk` | **Владелец** | лавандовый, звезда |

Сопоставление идёт по **нику**, а не по номеру аккаунта: чужие айди в сборку
не вшиваются. Те же две записи есть и внутри приложения — на случай, если
файл ещё не скачался. Значок виден в списке чатов и в профиле, по нажатию
открывается окно с иконкой.

Значок ничего не удостоверяет — это украшение.

## Что изменилось по сравнению с MargyGram

- Видимые пользователю названия заменены на `Hayo`/`Hayo Gram`. Пакет остаётся
  `cat.narezany.margygram` — это та же программа, что и исходный форк.
- Автор, канал и обратная связь ведут на `@hayozimi`, исходники — сюда.
- Платёжные реквизиты, ссылки на донат и серверы прежнего автора удалены,
  а не перенесены. Экран доната больше не предлагает способов оплаты.
- В `badges.json` только два значка владельцев; добавлены поля `username`
  и `icon` (`crown` / `star`) помимо старого числового `peer`.
- Запрос значков OtherGram, который отправляет айди людей на сторонний сервер,
  **по умолчанию выключен**.
- Удалённые файлы (значки, версия) читаются из этого репозитория на GitHub.

Остальные функции форка (плагины, музыка, режим стримера, темы и т.д.)
сохранены. См. [ATTRIBUTION.md](ATTRIBUTION.md).

## Сборка

Готового APK в репозитории нет. Для сборки нужны SDK 36, build-tools 36.0.0,
NDK 27.2.12479018 и JDK 21.

1. **GitHub Actions.** Сделайте форк, добавьте свои `HAYO_APP_ID` и
   `HAYO_APP_HASH` в Secrets (получить можно на my.telegram.org) и запустите
   workflow *Build APK*. APK будет вложен в артефакты запуска.
2. **Свой компьютер.** Инструкция в [BUILD.md](BUILD.md).

Свои ключи API в репозиторий не кладутся. Публичные ключи Telegram годятся
разве что для пробной сборки.

## Безопасность

У плагинов нет песочницы: плагин выполняется внутри приложения, видит чаты,
может отправлять сообщения и читать файлы. Ставьте только те, чей код вы
прочитали. Полный разбор патча — в [docs/security.md](docs/security.md).
