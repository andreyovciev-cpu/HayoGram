# Плагины Hayo Gram

[English](plugins.md) · **Русский** · [中文](plugins.zh.md)

Плагин — это код на Python, который выполняется **внутри** Hayo Gram. Не
отдельное приложение и не бот.

## Сначала прочитайте это

У плагинов **нет песочницы**. Плагин видит ваши чаты, может писать от вашего
имени и работать с файлами, доступными приложению. Разрешения в манифесте —
всего лишь заявление автора: приложение их не проверяет и не ограничивает.
Ставьте только те плагины, чей код вы прочитали и которому доверяете.

Код плагина не должен обфусироваться: любой человек должен прочитать, что он
делает.

## Формат

`.marp` — обычный zip:

```
plugin.marp
├── manifest.json   обязательно
├── main.py         обязательно
├── icon.png        необязательно
└── ...             всё остальное, что нужно плагину
```

```json
{
  "id": "hayo.example",
  "name": "Пример",
  "version": "1.0",
  "author": "hayozimi",
  "description": "Пишет привет в консоль.",
  "min_version": "2.0",
  "permissions": ["ui"]
}
```

Для переводов есть поля `name_en`, `name_zh`, `description_en`, `description_zh`.

## Минимальный плагин

```python
def on_start():
    margelet.log("привет из Hayo Gram", margelet.name)
```

`on_start()` вызывается при запуске плагина. Без него файл просто выполняется
сверху вниз.

Глобальный объект `margelet` даёт `log`, `error`, `toast`, `ui`, `background`,
`every`, `cancel`, `get`, `set`, `flag`, `fetch`, `window`, `send`, `activity`
и хуки `on_chat_opened`, `on_send`, `on_message`, `on_deleted`, `on_pin`,
`button`, `on_settings`, `pick_file`.

Плагины по умолчанию выключены. Новый плагин остаётся выключенным, пока вы его
не включите.
